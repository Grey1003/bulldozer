# 当前米筐选股规则完整对照

核对日期：2026-10-27。以当前 `configs/default.json` 和 `src/strategy/` 实现为准。
入口是 `python select_stocks.py` 或 `python main.py screen --date YYYY-MM-DD`。
本文件总结米筐模块化选股流程，不混入仓库另一个 BaoStock 入口 `bulldozer.py` 的规则。
2026-10-27更新：二波反弹改为仅报告提示；8日累计涨幅改为6%～40%；
新增最近5日最低价触及或跌破当日MA20即剔除。近期涨停次数要求仍已删除。

## 1. 总体判定

先检查股票资格，再计算12项形态规则。资格合格并且12项全部通过才入选。
没有加权评分、选取前N名、凑够数量或自动放宽参数。

以下T是实际研究交易日，所有“最近N日”均包含T，除非明确写出排除T附近窗口。
窗口均为交易日；只有上市天数是自然日。

## 2. 日期与数据口径

- 输入T表示T日收盘后的选股，用于之后的人工观察，不是T日开盘前可知的候选。
- 首先检查日期是否在缓存 `metadata.json` 的起止范围内，超出直接报错。
- 在缓存范围内的非交易日，映射到此前最近交易日。缓存终点之外的周末也会报错，
  不会先自动映射到终点。
- 仅读取T及之前的行情；仅读取生效日不晚于T的复权事件。
- 默认下载近5个自然年；但每次选股默认读取最近180个市场交易日，绘图展示末120日。
- 实际读取窗口是以下数值的最大值：绘图长度+60、最少历史长度、二波回看长度、
  形态窗口+60、连板检查窗口。默认对应180日。
- OHLC用于形态和均线前，转换成研究日时点前复权价：
  `原始价[t] × 累计复权因子[t] / 累计复权因子[T]`。
- 因子按生效日向历史匹配；完整上市以来除权记录中，首次事件前因子为1。
  不用未来因子反向填充。
- 每日收益率 `r[t] = 原始收盘价[t] / 米筐prev_close[t] - 1`。
- 日内振幅 `a[t] = (原始最高价[t] - 原始最低价[t]) / prev_close[t]`。
- 成交量保持不复权。选股只用成交量大于0判断交易状态，不设放量或缩量门槛。
- 股票名称为下载时名称，仅展示；ST使用历史日期标记。
- 股票池保留下载区间存在过的股票，包括后来退市的股票，再按T判断上市/退市状态。
- 供应商可能回修历史记录，本实现不等于还原每个历史时点供应商数据库的原始版本。

## 3. 股票资格

以下任意一项不满足即停止该股后续形态计算。

| 项目 | 当前要求 | 配置或代码 |
| --- | --- | --- |
| 板块 | 仅代码前缀000、001、002、003、600、601、603、605 | main_board_only=true |
| 上市状态 | 上市日不晚于T；退市日为空或晚于T | 固定日期判断 |
| 上市时间 | T距离上市日至少120自然日 | min_listing_days=120 |
| 历史长度 | 读取窗口内至少120条日线；历史零成交记录也计条数 | min_history_bars=120 |
| 当日行情 | 个股最后一条日线必须是T | 固定判断 |
| 当日交易 | T成交量必须大于0 | 固定判断 |
| ST状态 | T历史ST标记不能缺失，且必须不是ST | exclude_st=true |
| 近期日期 | 个股末8条日线日期必须与市场末8个交易日逐一相同 | trend_days=8 |

当前没有对历史全部120日要求无停牌，也没有按名称字符串判断ST。

## 4. 十二项形态规则

先计算MA5、MA10、MA20、MA60，全部为含当日收盘价的简单移动平均。
MA60只展示，不参与多头排列或斜率过滤。

| 序号 | 规则名称 | 当前实际通过条件 | 参数 |
| --- | --- | --- | --- |
| 1 | 近期无停牌及缺失行情 | 最近8日每天成交量>0，OHLC均为有限数值 | trend_days=8 |
| 2 | 五日均线持续向上 | 最近8日中至少7日满足MA5[t]>MA5[t-1] | min_ma5_up_ratio=0.875 |
| 3 | 均线多头且中期向上 | 最近8日至少6日MA5>MA10>MA20，且MA20[T]>MA20[T-5] | min_bullish_ma_ratio=0.75 |
| 4 | 收盘未远离五日线 | 最近8日每一天close/MA5-1都≤8% | max_close_ma5_distance=0.08 |
| 5 | K线下沿贴近五日线 | 最近8日至少6日abs(low/MA5-1)≤3.5% | max_low_ma5_distance=0.035；min_touch_ratio=0.75 |
| 6 | 收盘未明显跌破五日线 | 最近8日每一天close/MA5-1都≥-2% | max_below_ma5=0.02 |
| 7 | 爬坡涨幅适中 | 最近8日日收益率复合累计涨幅介于6%与40%，含边界 | min_trend_return=0.06；max_trend_return=0.40 |
| 8 | 日内振幅适中 | 最近8日平均振幅介于2%与9%，且其中最大单日振幅≤13% | min_mean_amplitude=0.02；max_mean_amplitude=0.09；max_daily_amplitude=0.13 |
| 9 | 末日未大涨或过度偏离 | T日收益率≤6.5%，且T日close/MA5-1≤5% | max_last_return=0.065；max_last_ma5_distance=0.05 |
| 10 | 近期无连续涨停 | 最近15日窗口内最大连续收盘涨停天数≤1 | consecutive_limit_days=15；max_consecutive_limit_up=1 |
| 11 | 末段未突然加速 | 不是同时满足“加速倍数>2.5”与“最近3日复合涨幅>6%” | acceleration_days=3；max_acceleration_ratio=2.5；acceleration_min_return=0.06 |
| 12 | 近五日最低价未触及MA20 | 最近5个市场交易日（含T）每天low>当日MA20；等于或跌破即淘汰 | ma20_touch_days=5 |

## 5. 特殊计算详解

### 5.1 收盘涨停

必须同时满足：

1. 原始收盘价与米筐历史涨停价的绝对差≤0.005元，比较不加相对误差。
2. `limit_up / prev_close` 在1.01至1.31之间，含边界。
3. 当天成交量>0。

盘中触及涨停但收盘打开，不计涨停。不以“涨幅≥9.9%”替代实际涨停价格。
不再要求近期至少一次涨停；仍保留不能连板的过滤。
连续涨停只在15日窗口内计算，窗口外连板不纳入。

### 5.2 最近8日复合涨幅

`R8 = ∏(1+r[t]) - 1`，共8个日收益率。
并不是T日收盘除以这8根K线中第一天收盘；后者通常只包含7个日变化。
在无除权等特殊影响时，更接近T日收盘相对T-8日收盘的变化。

### 5.3 加速过滤

只在最近8日内比较前5日与后3日：

```text
positive_return[t] = max(r[t], 0)
base_speed = max(前5日positive_return平均值, 0.003)
recent_speed = 后3日positive_return平均值
acceleration_ratio = recent_speed / base_speed
R3 = 后3日真实收益率的复合累计涨幅
```

只有 `acceleration_ratio > 2.5 AND R3 > 0.06` 才淘汰。
两者任一不满足就通过；等于2.5或等于6%不会因本项淘汰。
负收益在速度均值中记作0，但计算R3时保留负收益。
0.3%的基准下限固定写在代码中，当前不在JSON参数里。

### 5.4 二波反弹提示（不参与筛选）

1. 取最近100个交易日。
2. 排除末8日，剩下前92日为旧走势区间。
3. 取旧区间最高high作为旧高A；最高价并列时取最先出现的位置。
4. 从A所在交易日开始，到旧区间末日，找最低low作为低点B。
   A日也包含在低点搜索内，日线无法知道同一天内高低点的先后。
5. 计算 `drawdown = 1-B/A` 和 `peak_distance = close[T]/A-1`。
6. `drawdown >= 0.18 AND peak_distance <= 0.08` 时标为“明显二波反弹：是”，
   否则标为“否”。仅报告提示，不计入failed_count、failed_rules或入选判定。
7. HTML、单股日期诊断和CSV保留is_rebound、prior_drawdown、prior_peak_distance。

注意：这不只排除“快到旧高”的股票，也会排除仍远低于旧高的股票。
当前既不识别完整波浪，也不要求B是被左右K线确认的局部低点；
它只是“先找旧高、再找其后低点”的宽泛历史形态代理。
超过旧高8%的股票标为“否”；二波标签均不影响筛选。

### 5.5 最近五日MA20下探剔除

使用与K线相同的时点前复权最低价，以及包含当日收盘的20日简单均线。
检查T-4至T共5个市场交易日，任一天`low <= MA20`即淘汰。
不是将5日最低价与T日MA20比较，也不使用次日均线。
输出ma20_touch_count、ma20_touch_dates以及min_low_ma20_distance。
其中距离为各日`low/MA20-1`的窗口最小值，正数表示每天均在线上。

## 6. 不容易从规则名称看出的细节

- “连续8日沿线向上”实际允许1日MA5不升，不要求8个阳线或8日股价上涨。
- “均线发散”实际检查多头顺序与MA20五日方向，不检查均线间距是否越来越大。
- MA20只比较两个端点，不要求中间每天都向上。
- “贴线”看最低价的绝对距离，不要求K线实体接触MA5，允许低点在线下3.5%内。
- 但收盘在最近8日中任何一天跌破MA5超过2%，仍会被支撑规则淘汰。
- 最后一天实际需要同时满足：收盘相对MA5在-2%至+5%之间。
- “末日涨幅≤6.5%”仅有上限，不是绝对涨跌幅≤6.5%，没有单独的末日跌幅下限。
- 均线、贴线、累计涨幅等多条约束叠加；某一项通过不等于整只股票通过。
- 3.5%、2%、8%、6.5%、18%等精确阈值及AND组合是工程设定，
  不能当作两份原文已经给出的唯一公式。

## 7. 报告、排序与人工复核

- 所有结果先按失败规则数量升序，再按股票代码升序排列；不是按收益或形态分数排名。
- 入选股票全部画图，没有最多选几只的限制。
- 默认展示12只已通过资格、但未通过全部形态规则的复核样本。
  它们不是入选股，也不是备选买入名单。
- `failed_count` 为未通过形态规则数；资格不合格时固定写13，
  这个13是排序占位值，不表示实际失败13条。
- `diagnostics.csv` 保存资格、指标、逐项pass列、失败数和失败原因。
- `selected.csv` 只保存全部通过的股票。
- `parameters.json` 是本次完整参数；`run.json` 保存研究日、数据边界和规则淘汰数量。
- 同一股票可能同时失败多条规则，因此各规则淘汰数量不能直接相加。
- K线默认120日；MA5/10/20/60；黄色区域为末8日；红三角为收盘涨停。
- 成交量柱用于观察，成交量数值及变化不进入形态筛选。
- HTML/PNG由标准选股程序生成；PDF由自动任务另行导出，不是12条规则的一部分。

## 8. 次日均线估计

`next_ma5_estimate = (最近4个收盘价之和 + T日收盘价) / 5`。
其中最近4个已经包含T，所以T日收盘价在分子中出现两次。
意义是“假设次日价格与T收盘相同”时的MA5；不读取次日实际行情。
该字段仅输出，不参与选股、不构成委托价格，也未验证成交可能性。

## 9. 当前未实现的条件

不使用市值、行业、题材、财务、量比、换手率、成交额大小、成交量放缩、
指数环境、北向资金或资金流指标。
不要求股价创新高，不设明确日内跳空或上影线长度限制，
不要求所有均线都发散上行，不设专门的一字板过滤或全历史连板过滤。
不识别集合竞价、9:40前下杀、盘中实时MA5、实际委托或成交。
不实现仓位控制、止盈止损、隔日卖出、持仓或收益回测。
仓库另一个程序中的回测功能不会被 `select_stocks.py` 调用。

## 10. 下载与参数约束

- years=5；batch_size=100，按股票分批下载。
- 北京时间16:00前，下载终点最多为昨日；16:00起可请求当日，但仍须供应商已更新。
- 同一区间与批次大小可续传；区间或批次改变时，当前下载器要求新缓存目录。
- 已有价格和因子批次会直接复用，不自动补拉较晚更新的行情。
  因此供应商尚未更新时留下的批次，需要另行刷新，不能假定重跑就会更新。
- 下载完成检查的是全体批次的最大行情日期；并非逐股都必须有当日数据。
  个股缺少T行情会在资格阶段排除。
- 历史ST必须与价格唯一键一一对齐，缺失会中止下载。
- `acceleration_days` 必须为正且小于 `trend_days`。
- `min_history_bars` 至少为以下数值最大值：60、trend_days+1、rebound_days、
  consecutive_limit_days、ma20_touch_days+19。当前要求至少100，配置实际使用120。
- 配置中的比例采用小数，例如0.05表示5%；相对路径按项目根目录解析。
